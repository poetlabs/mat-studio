One-time setup: the portal bookmark

Sends the portal's design queue (or one order) to this studio. Add it once (copy it again if you added an older version):

  1. Press Ctrl+Shift+B to show the bookmarks bar.
  2. Right-click the bar, choose Add page… (Edge: Add favourite).
  3. Name: Send to Mat Studio. URL: delete what is there and press Ctrl+V. Save.

Then click the bookmark on the portal's design queue page: every sketch is added to the order queue here and designed. On a single order page it opens that order here.
